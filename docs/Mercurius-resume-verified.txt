Mercurius | 跨境购物智能体 | 独立开发者
面向跨境购物的多条件选品需求，通过多轮交互理解偏好，完成商品搜索、比较与筛选，生成附理由和来源的推荐清单。

• 任务编排与专家派发：基于 AgentScope ReAct 组织购物任务，主 Agent 处理简单请求，通过 Task 工具派发搜索、交易专家，子任务保持独立上下文并支持并行；四搜索子任务受控对照中，执行阶段耗时降低65.4%。
• 上下文与偏好管理：压缩历史并保留近期消息，结合摘要与结构化状态维护预算、商品标识和待确认动作；独立注入长期偏好，完整保留已存负向偏好，按相关性选取正向偏好，支持跨会话读取与删除；12轮购物流程对照中总输入Token减少33.4%，压缩组缓存输入Token占比约80.5%，48项业务检查通过。
• 执行保护与异常追踪：为工具配置分级超时与熔断，对模型暂态错误设置重试和备用模型回退，为任务与偏好工具加入重复调用提醒；13个需求的正常、限流及首段连接故障分层验收中通过39/39项；结合OpenTelemetry与业务事件按请求关联首次失败，小规模人工定位验收中作答耗时中位数48.7秒→22.2秒。
