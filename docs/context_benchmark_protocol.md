# 简历第二条：上下文压缩与事实保留对照

2026-10-02，运行前冻结。只研究现有上下文机制，不改app、不扩展路由/检索/故障实验。12个Codex合成轨迹，3组，每例一次；探索性数据，非用户流量或独立人工标注。

## 输入与三组

每例含15/20/24轮冻结历史与6轮继续输入，共21/26/30轮。历史中的用户/助手文本为明确标注的合成回放，商品事实摘自本地种子库；不把回放轮数称为真实模型交互轮数。继续阶段每轮调用真实模型，回答当前购物状态的9字段JSON；不执行订单或联网，不称端到端购物完成。实际模型答案不重新写入history，以免连续探针把答案不断提示给下一轮；追加的中性助手回执各组相同。

- full_history：全部历史，不压缩、不挂事实侧账本。
- summary_recent：原有ContextConfig摘要+近期消息，不挂事实侧账本。
- summary_facts：相同摘要策略+原有CriticalFactsMiddleware；不额外预填gold或实现更强状态抽取器。

固定受控context_size=4096、trigger=.75、reserve=.15。模型真实窗口仍由provider控制；缩小配置仅为触发机制，不是线上128k触发率。每轮压缩前计数，summary组调用原有compress_context；自动跳过未到阈值的轮次。full与summary对比隔离摘要，两个summary组对比原有侧账本；侧账本会影响摘要输入和触发时间，这属于该完整机制的效应。

覆盖稳定要求、预算替换、国家替换、商品切换、品牌排除撤回、商品类型排除撤回、临时例外、购买意向撤回、多次修改、无关数字干扰。当前预算单位CNY；本轮只测试明确当前约束，不验证汇率或真实商品推荐质量。pending_action只允许awaiting_confirmation/none，不把待确认当已下单。

## 固定评分

九字段budget/currency/country/excluded_brands/excluded_types/product_id/quantity/pending_action/selected_title。允许JSON外层代码围栏，不允许额外解释；必须为完整对象且无多余字段。数字只接受number且排除bool，数组按去重集合比较并拒绝重复，字符串精确比较。每题expected逐轮在调用前固定。字段正确数/总字段数、整轮全对/计划轮数、6轮全对/案例数分别报告；超时、无输出、schema错误、API错误均保留且不通过。

正式运行前的pilot修正：接口pilot把refurbished译词判为不同于翻新商品，这是评分格式误判，不是丢失排除条件。正式评分增加固定别名表：excluded_types中的refurbished（忽略大小写）、翻新、翻新机均映射到翻新商品；used不映射。其余字段仍按上述规则。pilot原始分数不改、明确不纳入正式比较。修正发生在查看任何正式用例输出之前，此后不再改评分。

成功意味着结构化状态探针通过，不表示能完成购物。侧账本历史事实不保证等于当前意图，专门保留用户更新与旧工具结果冲突的用例。测评脚本不根据答案修订题目或判分。

## 成本与公平性

seed=20261002用于配对执行顺序。temperature=0，实际请求保留；provider随机性无法完全消除。同一模型名、工具格式、max_tokens=2048、stream、关闭SDK隐式重试、模型重试/备用模型也关闭。所有组明确设置DeepSeek thinking disabled，避免旧实验默认思考模式不支持强制tool_choice造成兼容重发；这是统一实验配置，不是业务修改，不能与旧思考配置混合比较。
